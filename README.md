# Flappy Bird (Jack) - Hito 1: Tablero y Objetos Gráficos

**Asignatura:** Organización de Computadores
**Institución:** Universidad EAFIT
**Autor:** Alejandro Restrepo Osorio

## Descripción General
Este proyecto es una implementación de un videojuego de estilo retro (clon de Flappy Bird) desarrollado en el lenguaje de programación orientado a objetos Jack, diseñado para ejecutarse sobre la máquina virtual de la arquitectura de hardware Hack (plataforma Nand2Tetris). 

Esta entrega corresponde al **Hito 1 (Tercer Parcial)** y se enfoca en la estructuración modular, el modelado de clases, la gestión de memoria y el renderizado del escenario dinámico junto con los objetos gráficos iniciales.
